# Customer Churn Prediction

ML-проект по прогнозированию оттока клиентов телеком-компании.

## Задача

Построить модель бинарной классификации для определения клиентов
с высоким риском ухода и выявить основные факторы оттока.

## Данные

Датасет содержит информацию о клиентах телеком-компании:
тип договора, срок обслуживания, ежемесячные платежи,
подключенные услуги и другие характеристики.

Целевая переменная — Churn.

## Что сделано

- проведен EDA;
- обработаны категориальные признаки с помощью One-Hot Encoding;
- выполнено масштабирование признаков;
- исследован PCA;
- обучены Logistic Regression, KNN, SVM, Random Forest и XGBoost;
- использована Stratified Cross-Validation;
- выполнен подбор гиперпараметров с GridSearchCV и Optuna;
- подобран оптимальный classification threshold;
- выполнен SHAP-анализ;
- клиенты сегментированы по риску ухода.

## Результаты

Лучшей моделью оказался XGBoost:

- CV ROC-AUC: 0.843
- Test ROC-AUC: 0.833
- оптимальный classification threshold: 0.272

SHAP-анализ позволил определить основные факторы риска оттока.

Оцененная выручка, находящаяся под риском:
$42,019.

## Бизнес-выводы

Наиболее высокий риск оттока наблюдается у клиентов:

- с помесячными контрактами;
- с высокими ежемесячными платежами;
- использующих электронную оплату;
- не подключивших ряд дополнительных услуг.

На основе результатов сформированы рекомендации по удержанию клиентов.
